# Як зробити внесок у проект

Ми раді будь-якій допомозі! Щоб запропонувати зміни:
1. Зробіть Fork цього репозиторію.
2. Створіть нову гілку для вашої фічі (`git checkout -b feature/AmazingFeature`).
3. Внесіть зміни та перевірте їхню працездатність (запустіть Unit-тести, якщо вони є).
4. Зробіть Commit змін (`git commit -m 'Додано нову функцію'`).
5. Зробіть Push у гілку (`git push origin feature/AmazingFeature`).
6. Відкрийте Pull Request, детально описавши ваші зміни.
